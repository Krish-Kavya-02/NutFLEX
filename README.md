# 🍒🍒 NutFLEX - Latest Movie and TV Shows Update

## Overview
NutFLEX is a dynamic and interactive movie and TV show dashboard that provides real-time updates on the latest releases and trending content. Built with React.js, it integrates the TMDb API to fetch and display movie and TV show data, allowing users to search by name or genre and view details such as ratings, trailers, cast information, and summaries.

## Features
- **Real-time Movie & TV Show Data**: Fetches latest releases and trending content from TMDb API.
- **Search & Filter**: Allows users to search movies and TV shows by name or genre.
- **Detailed Information**: Displays ratings, trailers, cast information, and summaries.
- **Bookmarking (Bonus Feature)**: Users can save their favorite movies and shows.
- **Responsive UI**: Optimized for mobile and desktop viewing with smooth animations.

## Tech Stack
- **Frontend**: React.js (HTML, CSS, JavaScript)
- **API**: TMDb API
- **Styling**: Tailwind CSS / Styled Components

## Installation
### 1. Clone the Repository
```sh
git clone https://github.com/yourusername/NutFLEX.git
cd NutFlex
```

### 2. Install Dependencies
```sh
npm install
```

### 3. Create a `.env` File
Add your TMDb API key in a `.env` file at the root of the project:
```
REACT_APP_TMDB_API_KEY=your_tmdb_api_key
```

### 4. Run the Project
```sh
npm start
```
The app will be available at `http://localhost:3000/`.

## Usage
- Use the search bar to find movies and TV shows by name or genre.
- Click on any movie/show to view detailed information.
- Bookmark movies/shows to access them later.

## API Integration
This project uses the [TMDb API](https://www.themoviedb.org/documentation/api) to fetch movie and TV show data. Make sure to generate an API key and store it in the `.env` file.
